# Comparison tooling

Scripts for checking the re-creation against the installed Obsidian 1.14.4 without touching the owner's running app. Both apps run as hidden, offscreen Electron processes on throwaway vaults under the temp directory, and are driven through Chromium's remote debugging port.

## The two fixtures

| | Start | Default port | Vault |
| --- | --- | --- | --- |
| Reference (installed Obsidian) | `node scripts/dev/launch-reference-fixture.mjs [existing fixture dir]` | 9351 | `%TEMP%/obsen-reference-audit-*/vault` |
| Re-creation | `node scripts/electron-smoke.mjs --bases-compare` (stays running; start it in the background) | 9341 | `%TEMP%/obsen-electron-smoke-*/vault` |

Stop either with `node scripts/dev/stop-app.mjs <port>`. Never pass 9229: that is the owner's own Obsidian.

`fixture-client.mjs` connects to a fixture and refuses any page whose vault is not one of these temp fixtures. It offers `evaluate`, `wait`, `click`, `key`, `send` (raw protocol), `capture(dir, name, selector)` (PNG plus a JSON DOM outline of the element), and collects renderer exceptions in `errors`. In the re-creation the app object is `window.__obsenSmokeApp` right after a reload and `app` afterwards; in the reference it is `app`.

PDF and sidebar workflow audits request `separateHistoricalErrors`: debugger logs replayed on connection are saved as `historicalErrors`, then the console history is cleared after the temporary-vault guard passes. Current-run errors still fail the audit. This prevents earlier deliberate page-99 diagnostics contaminating later runs; startup coverage belongs to the fresh full Electron smoke test. Historical logs remain in each report for inspection.

Things that bite:

- An offscreen window only produces a frame when something changed. `Page.captureScreenshot` on an idle page never resolves, so race warm-up captures against a short delay.
- The reference only runs editor commands when the editor has focus (not the inline title). Call `editor.focus()` first.
- After changing a plugin's JSON options the re-creation needs `Page.reload`; the reference can have `plugin.instance.options` patched in place.
- Totals that depend on how many times a script ran in a fixture (snapshot counts, history) differ between the two; compare what the run itself produced.

## Audit scripts

- `popout-appearance-audit.mjs` — three paired live dark/light/title checks in hidden popouts, plus raw vault font writes retaining the initialized per-device font preference. Uses native setBaseFontSize and own typed config only for equal setup/restoration; the compared actions use raw vault config. The Node follow-up gate separately covers device migration/raw JSON/reopen behavior. Writes `popout-appearance-comparison/report.json`.
- `npm run test:graph` — exercises the generated Rust/WASM module directly: append keeps ongoing velocity and fixed positions, deduplicates IDs and accepts new links. Generate the WASM package with `npm run build:graph:wasm` when Rust sources change; this is required before validating fresh graph artifacts.

- `linked-editor-audit.mjs` — thirteen paired checks on the root fixture ports 9352/9342 for source selections/carets, scrolling, unlinking, source/reading exchange, programmatic-scroll suppression and a hidden source popout. Seeds a short-line note and collapses docks equally. Cursor/selection/source state matches exactly; fractional source-line scroll positions permit 0.05 lines for CSS-pixel quantization. Captures no OS input/clipboard and closes only its created panes/popout. Writes `linked-editor-comparison/report.json`.
- `line-break-audit.mjs` — eight paired paragraph/hard-break/quote/list cases with Strict line breaks off/on. Compares exact saved source, paragraph text and break counts. Restores the preference and closes its dedicated leaf. Writes `line-break-comparison/report.json`.
- `startup-audit.mjs` — thirteen desktop reload cases, including daily templates/existing/disabled/pinned/default modes, nested paths, autorun migration, missing specific files and new-note behavior. A community-plugin onload probe verifies desktop startup ordering. Reload only unchanged archives: restart exact own fixtures after rebuilding.
- `startup-cold-audit.mjs` — four fresh-process paired daily-note cases (fresh, existing, legacy autorun, disabled). Creates separate guarded TEMP vault/profile roots and stops its own child handles. `--only=obsen` is discovery, not paired proof. The hidden BrowserWindow subclass must be named BrowserWindow for Electron window enumeration. Writes `startup-cold-comparison/report.json`.

- `property-daily-note-audit.mjs` — twenty-eight guarded paired checks for date-link appearance and actual note creation/navigation in Markdown source/reading, file properties, hover, canvas and a hidden Markdown popout. Exercises current/tab/split/popout modifiers, template content, pending-date save/selection and widget state across Daily notes disable/re-enable. Deletes only its named temporary daily targets before each run, restores option JSON/reference options, and closes its panes/popouts. Scopes clicks to the owned note pane and returns void from leaf-inventory callbacks. Expands both left docks for two comparable property captures; focuses the canvas card before activating its link. Most clicks use Chromium input; child click and pending input are explicitly synthetic. Writes `property-daily-note-comparison/`. Native child input/pickers, pins, custom/failure settings and startup are outside this gate.

- `property-tag-action-audit.mjs` — eight guarded paired checks for tag Search actions using Chromium plain/Ctrl/Shift/double clicks, a synthetic selected-text click and actual Search plugin disable/re-enable through settings. Creates a dedicated document/property pane and checks queries, editing state and source preservation. It leaves Search enabled after the gate; the fixture is temporary. Writes `property-tag-action-comparison/report.json`.
- `property-date-audit.mjs` — seventeen guarded paired checks for date/datetime source, controls and focus: seconds, pending input, Enter/blur/Escape, empty values, assigned formats/empty strings, scoped inference and a file-properties popout save/close. Uses DOM input events, Chromium keys in the main window and an explicitly untrusted child-window Enter event. Records two main-pane captures under `property-date-comparison/`; native picker, full popout keyboard and daily-note creation/routing are outside this gate.

- `property-input-audit.mjs` — 42 guarded paired checks for list whitespace, aliases/tags duplicates and case variants, inline duplicate edit/cancel, loaded duplicates/blank values, plain/multiline/rich/HTML-only/URI-list paste and composing-key suppression. Uses trusted Chromium typing/keys plus explicitly untrusted local ClipboardEvent/composing KeyboardEvent probes; leaves the OS clipboard alone. Resets a dedicated property pane between cases, compares exact source/pills/focus/input structure, and records four actual blurred-control captures in `property-input-comparison/`. Real IME, OS integration, unsupported-insertText fallback, other hosts and popouts are outside this gate.

- `property-repair-audit.mjs` — twenty-eight guarded paired checks for aliases/tags/cssclasses mismatches: six confirmation/cancel/update/edit sequences and four file-switch/value-change states. Verifies source remains unchanged until editing, adapted controls, warnings and focus. Seeds tag/plain-property suggestions and captures twelve dialogs/controls in `property-repair-comparison/`. `--only=reference` supports discovery and does not constitute parity evidence. Other property hosts, popouts, paste/IME and broad conversions remain outside this gate.

- `property-list-audit.mjs` — twenty guarded paired checks on 9352/9342 for list/alias/tag editing, exact saved YAML, input/pill focus, inline editing, Backspace/arrows/Escape, ordinary-list duplicates, tag validation and fuzzy suggestion selection, pill menu entries and intercepted Copy callbacks. Creates and removes a dedicated document leaf and property pane so prior pending edits cannot contaminate the run. Seeds and waits for a known tag inventory, primes the offscreen compositor, and records exact input/popup geometry with a suggestion capture. Copy writes are intercepted at the navigator method and its descriptor is restored; the OS clipboard is untouched. Cross-host/popout lifecycle, paste/IME, links, broader validation and alias/tag duplicate cases remain outside this gate.

- `property-edge-audit.mjs` — eighteen guarded paired checks for sixteen YAML/value cases, Show source navigation, and four global unknown-property icons. Covers reserved numeric/boolean/object/mixed-list values, nullable text lists, case-insensitive reserved names, invalid frontmatter and recovery. Verifies exact source preservation and captures twenty widgets/rows under `property-reserved-comparison/`. Filters global rows to the seeded prefix so unrelated notes do not change scrollbars or capture geometry. Primes the offscreen compositor and removes temporary document/global panes. Earlier paired prototype-name failure evidence remains in `property-edge-comparison/`; the reference global list crashes on those names.
- `property-prototype-audit.mjs` — five own-fixture robustness checks for renaming to constructor/__proto__, available type menus and the unfiltered global list. Creates and removes temporary document/property/global panes. This is deliberately separate from parity evidence because the reference global-property dictionary fails on those keys. Node workspace tests independently verify safe type assignment persistence for these names.

Both isolated launchers install `fixture-crash-diagnostics.cjs`. Each fixture directory contains `crash-events.jsonl` and a `crashes/` directory. Diagnostics record renderer/child process exits and unresponsive renderers, with local Electron crash dumps and uploads disabled. A passing run or an empty dump directory does not identify an earlier Windows error from another process.

The sidebar audit's `--only=propertyCrud,propertyEdit` compares five property conflict cases, merge confirmation, deletion and text/number/checkbox editing with saved values and focus. Setup detaches an old on-demand file-properties leaf before replacing the temporary vault, so previous runs' deleted file bindings do not contaminate captures.

`python scripts/dev/compare-capture-pixels.py <dir>` writes `pixel-report.json` for every `reference-*.png` / `obsen-*.png` pair (share of pixels differing by more than 10 levels).

Both comparison launchers now use `--disable-lcd-text` so that text rasterization has the same settings in the two offscreen processes. Before this was standardized, identical menu geometry/styles produced large text-edge differences. This flag is confined to comparison fixtures; report the capture conditions with pixel results.

Several people can compare at once if each uses its own bundle and ports:

```
node scripts/dev/build-isolated.mjs dist/w1                 # build into dist/w1 (no type check)
OBSEN_DIST=dist/w1 OBSEN_SMOKE_PORT=9342 node scripts/electron-smoke.mjs --bases-compare   # re-creation fixture on 9342
OBSEN_REFERENCE_PORT=9352 node scripts/dev/launch-reference-fixture.mjs                    # reference fixture on 9352
```

After a source change: rebuild into the same directory, then stop and restart that isolated fixture. Reloading a running process after replacing its ASAR can reuse cached entry offsets and corrupt module loads. Check the fixture JSON's PID and process command line before stopping it; leave the owner's app alone. The source tree itself is shared, so parallel work still needs agreed file ownership, and `npm run build` / `npm test` / `dist/app.asar` belong to whoever is integrating.
