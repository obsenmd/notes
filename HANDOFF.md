## Goal

The owner's brief, verbatim:

> Finish making a faithful re-creation of obsidian in electron with tailwindcss, react, my custom graph viewer, and i18next for all of the copy.

Four constraints follow from it and have shaped every decision:

1. **Faithful** means DOM-and-pixel faithful to Obsidian 1.14.4, and behavior-faithful where behavior is observable. When a guess and the reference disagree, the reference wins.
2. **The custom graph viewer** (`src/graph/PixiGraph.tsx` and the WASM simulation in `graph-sim-wasm/`) is the owner's code. Keep it as the engine. Changes to it have been small and additive (extra props, a canvas-reuse fix); do not replace or restructure it.
3. **All copy goes through i18next.** No user-facing English literal in source. `brand.txt` rebrands "Obsidian" to "Obsen" in every string and overrides a few keys on purpose (for example the About row reads "API version", and account fields say "Username") — those are the owner's choices, not bugs.
4. **React + Tailwind + Electron.** Tailwind v4 is loaded without preflight and mapped to the app's CSS variables; most styling comes from the reference stylesheet.

## Method

The renderer emits Obsidian's exact DOM structure and class names so that the reference stylesheet (`assets/obsidian/app.css`, copied from 1.14.4) styles everything. New UI is written by reading how the reference builds that piece of DOM, emitting the same, and comparing.

The loop for any surface:

1. Find the structure in the reference: the stylesheet (`assets/obsidian/app.css`, search for the component's class prefix) and the reference bundle `app.js` (see "Reference material").
2. Find the copy: every English string is in `assets/obsidian/locales/en.json` under Obsidian's key namespace. Flatten it to grep for a phrase:
   `node -e "const f=(o,p='')=>Object.entries(o).flatMap(([k,v])=>typeof v==='object'?f(v,p+k+'.'):[p+k+' = '+JSON.stringify(v)]);console.log(f(require('./assets/obsidian/locales/en.json')).join('\n'))" > en-flat.txt`
3. Implement with `t("that.key")`. Only add a key under `obsen.*` in `src/locales/app/en.json` when Obsidian genuinely has no string for it.
4. `npx tsc --noEmit`, `node scripts/check-locale-keys.mjs`, build, launch, screenshot, compare.

### Build, run, drive

```
npm run build                       # tsc + tailwind + scripts/build-runtime.mjs -> dist/app.asar
npm run build:css && node scripts/build-runtime.mjs   # same without the type gate
npx electron . --user-data-dir=<profile dir> --remote-debugging-port=9340 --vault <vault dir>
node scripts/dev/cdp.mjs 9340 list
node scripts/dev/cdp.mjs 9340 eval '<expression>|@file.js' [targetIndex]
node scripts/dev/cdp.mjs 9340 shot out.png [targetIndex]
echo '[{"eval":"…"},{"wait":500},{"click":[x,y]},{"type":"text"},{"key":"Enter"},{"move":[x,y]},{"shot":"a.png"}]' | node scripts/dev/drive.mjs 9340 -
node scripts/dev/errors.mjs 9340 6  # reloads the page, prints exceptions and console errors
node scripts/dev/stop-app.mjs 9340
npm test                            # typecheck + locale keys + Node-side smoke tests
```

`window.app` in the renderer is the Obsidian-style `App` (vault, workspace, metadataCache, fileManager, commands). `app.commands.executeCommandById(id)` and `app.commands.listCommands()` are the quickest way to exercise things. Use a throwaway vault and profile directory; never point tests at a real vault.

Notes on the tooling:

- When a launch command pipes Electron's output, the shell call hangs until the app exits. Redirect to a file instead.
- Passing JavaScript with backslashes or newlines through shell quoting corrupts it. Put the expression in a file and use `@file.js`, or write a small `.mjs` patch script.
- Several source files have CRLF line endings; normalise before string-matching in scripts.
- The project is not a git repository. There is no undo other than your own backups.

## Traps found the hard way

- **View fields named `file`.** Sidebar panes treat `leaf.view.file` as a `TFile`. A view that stores a path string in a field called `file` crashes them (this took the whole window down once). Use another name.
- **Pixi and canvases.** Destroying a Pixi application loses the WebGL context of its canvas for good. `PixiGraph` now keys the canvas on its inputs so each re-run gets a fresh element, and waits for a non-zero size before creating the renderer. Keep both if you touch it.
- **`vault.rename`** used to leave the renamed file's own path untouched and was masked by the file watcher re-adding it. It is fixed; file objects are now updated in place, and code may rely on object identity surviving a rename.
- **`getFirstLinkpathDest`** returns a metadata record with a `.path`, not a `TFile`. Resolve it through `vault.getAbstractFileByPath` and compare paths, not objects.
- **Dialogs and pop-outs.** `Modal`, `Notice` and menus open in the focused window (`currentDocument()` in `src/compat/ui.ts`, Obsidian's `activeDocument`). Child windows share the renderer process, so window controls address them by title through the `window:control` IPC call.
- **Core plugin data** is read with `readCorePluginData(configDir, id)` (async, per-plugin JSON file). There is no synchronous accessor.
